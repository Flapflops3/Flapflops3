## 随窗而变 · AspectFit

**缩个窗口，还要来回调宽高？**

[AspectFit](https://github.com/Flapflops3/AspectFit) 是为《杀戮尖塔 2》做的 Windows Mod。拖动窗口任意一条边或一个角，宽高就会按所选比例一起变化。功能不大，解决的是小窗爬塔时反复调整窗口的麻烦。

**Why adjust the width, then the height, every time?**

[AspectFit](https://github.com/Flapflops3/AspectFit) is a Windows mod for Slay the Spire 2. Drag any window edge or corner and both dimensions resize together, keeping the selected aspect ratio. A small change for playing in a smaller window with less fiddling.
